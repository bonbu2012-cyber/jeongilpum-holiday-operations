# 대량 주문 엑셀 업로드

## 사용자 흐름

1. 운영자가 `/bulk-orders`에서 운영 암호를 확인한다.
2. `엑셀 양식 받기`로 현장수령·택배·배달 겸용 최신 15개 열 양식(`.xlsx`)을 내려받는다.
3. `주문입력` 시트 6행부터 주문을 작성한다 (참고용 `작성예시` 시트 및 VLOOKUP용 `상품목록` 시트 포함).
4. 상품명을 드롭다운에서 선택하면 단가와 수량에 따른 합계금액이 자동 수식으로 계산된다. '기타' 선택 시 단가와 수량을 직접 입력하고 비고란에 품목명을 적는다.
5. `.xlsx` 파일(또는 기존 앱의 `.csv` 파일)을 선택하면 브라우저가 열과 행 값을 읽고 오류, 주문 묶음, 결제상태, 총액을 미리보기 표에 표시한다.
6. 오류가 없을 때 `일괄 주문 업로드`를 누르면 서버가 현재 상품·한정수량을 검증하고 주문과 작업을 원자적으로 저장한다.

## 엑셀 계약 (15개 열 신규 표준)

`주문입력` 시트 이름과 5행 열 이름은 변경하지 않는다. 한 행은 상품 하나다. 한 파일에서 현장수령, 택배, 배달을 함께 작성할 수 있다.

| 번호 | 열 이름 | 적용 대상 | 규칙 및 기능 |
|---|---|---|---|
| 1 | 출고일(희망수령일)* | 공통 필수 | `YYYY-MM-DD` 형식, 한국 기준 오늘 이후 날짜다. |
| 2 | 수령방식* | 공통 필수 | 드롭다운 목록: `현장수령`, `택배`, `배달` 중 선택한다. |
| 3 | 주문자명* | 공통 필수 | 주문을 신청한 고객 또는 법인명이다. |
| 4 | 주문자연락처* | 공통 필수 | 0으로 시작하는 10~11자리 숫자 또는 하이픈 포함 연락처다. |
| 5 | 상품명* | 공통 필수 | 드롭다운 목록: 12개 정규 세트(`봉황세트`, `팔영세트`, `실속세트` 등) + `기타` 중 선택한다. |
| 6 | 수량* | 공통 필수 | 1~999 사이의 정수다. |
| 7 | 단가 | 자동/수동 | 정규 상품 선택 시 `상품목록` 참조 VLOOKUP으로 정가가 자동 입력된다. `기타` 선택 시 수동 입력한다. |
| 8 | 합계금액 | 자동 계산 | 엑셀 수식 `=수량*단가`로 실시간 자동 계산된다. |
| 9 | 받는사람 | 택배/배달 | 택배나 배달 수령 시 필수다 (현장수령은 비워둠). |
| 10 | 받는사람연락처 | 택배/배달 | 택배나 배달 수령 시 필수 (0으로 시작하는 10~11자리). |
| 11 | 받는사람주소 | 택배/배달 | 도로명주소 및 상세주소를 하나의 셀에 자유롭게 작성한다 (5자 이상). |
| 12 | 방문시간 | 현장수령 | 현장수령 시 픽업 희망시간이다 (예: `15:00`). |
| 13 | 배송메시지 | 택배/배달 선택 | 택배 기사님 또는 배달 전달용 요청사항이다. |
| 14 | 결제상태 | 공통 선택 | 드롭다운 목록: `미결제`, `결제완료` 중 선택한다. |
| 15 | 비고(기타상품내용/메모) | 선택/기타필수 | 상품명에서 `기타`를 선택한 경우 구체적인 품목명을 기재하며, 일반 주문 메모로도 활용된다. |

*하위 호환: 기존 16개 열 양식(`주문그룹키*` 포함) 및 기존 명절 관리앱의 `.csv` 파일 업로드도 완벽하게 지원한다.*

## 저장 및 연동 계약

- `POST /api/orders/bulk`는 운영 세션을 요구한다.
- `orders`: `payment_status`는 양식의 결제상태(`결제완료` -> `paid`, `미결제` -> `unpaid`)를 반영하며, 총 결제금액이 `total_amount`와 `paid_amount`에 기록된다.
- `order_items` & `work_items`:
  - 정규 세트는 카탈로그 `product_id`와 `price`를 연결한다.
  - `기타` 맞춤 상품은 `product_id='custom-order'`, 엑셀에 입력된 단가와 합계금액, `customization_json`에 비고 품목명을 보존하여 작업장과 판매장 상세 화면에 표시된다.
- `fulfillments`:
  - 현장수령: `pickup_at = ${scheduleDate}T${pickupTime || "10:00"}:00+09:00`, `delivery_method = 'onsite_reservation'`.
  - 택배/배달: `ship_date = scheduleDate`, `delivery_method = 'delivery'`, `road_addr`에 주소를 저장한다.
- 원자성: 모든 쿼리는 D1 `batch()` 트랜잭션으로 원자적으로 실행되며, 파일 해시 기반 Idempotency Key로 중복 접수를 방지한다.
