# 판매장·작업장 오늘 현황

## 판매장

- `/sales` 상단에 오늘 주문을 고객별로 묶어 수령 시간, 상품별 작업 상태, 결제 상태를 함께 표시한다.
- 현황은 3초마다 갱신되며 미결제·부분결제 주문은 결제 셀을 강조한다.
- 새 대량주문 양식은 `public/templates/jeongilpum-bulk-orders-pickup-time.xlsx`이며 현장수령시간을 08:00~21:00 사이 30분 단위로 선택할 수 있다.

## 작업장

- `/workshop` 상단에 오늘 봉황세트, 팔영세트, 오미트 시그니처, 오미트 프레스티지 주문을 부위별 스킨팩 필요 수량으로 합산해 표시한다.
- 세트 1개당 구성 부위별 스킨팩 1개로 계산하며 취소 주문은 제외한다.
- 작업 화면의 생산관리, 스킨팩, 이력추적, 패키지 바로가기 묶음은 숨긴다. 기존 데이터와 API는 삭제하지 않는다.
