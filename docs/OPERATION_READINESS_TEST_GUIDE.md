# 정일품 명절 예약 운영 웹앱 - 완성도 진단 및 수동 테스트 가이드

이 문서는 2026 추석 명절 대목 실전 투입을 앞두고, 시스템의 전반적인 완성도와 외부/내부 연동 상태를 최종 점검하고 현장에서 직접 수행해야 하는 수동 테스트 시나리오를 안내합니다.

---

## 1. 시스템 완성도 종합 평가

* **현재 완성도**: **약 95% (운영 배포 직전 최종 E2E 점검 단계)**
* **핵심 기능 구현**:
  * **고객 키오스크** (`/`, `/kiosk`): 일반 상품 주문, 맞춤주문, 방문수령 30분 단위 예약, 택배 발송지 입력 완비
  * **판매장 관리** (`/sales`): 날짜별 고밀도 주문표, 2.5초 자동 동기화, 결제 상태(미수/부분/완료) 실시간 집계 바 및 칩 필터, 고객 미수금/선수금 장부(Customer Ledger), 엑셀(CSV) 다운로드 완비
  * **작업장 화이트보드** (`/workshop`): 시간대별 작업 타임라인, 조기도착 우선 배치, 원클릭 상태 전이(`수락` → `시작` → `준비완료`) 완비
  * **출고 검수표 & 라벨 인쇄**: 2026 추석 공식 SOP 규격(162202/241702 용기 스킨팩 중량, V8 합포팩, 바구니 규격)을 100% 반영한 **A4 출고 검수표** 및 **50×50mm 감열 라벨(BEEPRT BY-48)** 인쇄 연동 완비
  * **안정성**: TypeScript 타입체크(`npm run typecheck`) **0 Error 완벽 통과**

### 💡 설계상 의도적으로 연동하지 않은 항목 (반드시 숙지할 점)

1. **PG사 전자결제 연동 (토스, KG이니시스 등 없음)**
   * **이유**: 정육점 명절 예약과 기업 단체 선물은 현장 카드 결제, 통장 계좌이체, 계약금 수납 후 출고 시 잔금 정산, 선수금/외상 관리 등 복잡한 정산 흐름을 가집니다.
   * **처리 방식**: 고객은 키오스크에서 결제 예정 수단(카드/현금/계좌이체/나중에 결정)을 선택하고, 직원이 실제 입금을 확인한 뒤 **판매장 화면의 [고객 결제/미수 장부]에서 수납 처리**합니다.
2. **카카오 알림톡 / SMS 자동 발송 연동 없음**
   * 현재 주문 완료 시 고객 휴대폰으로 알림톡이나 문자가 자동으로 발송되는 유료 메시징 API(Solapi, 알리고 등)는 연결되어 있지 않습니다. 주문 완료 화면에 주문번호와 안내 카드가 표시됩니다.
3. **클라우드 파일 업로드 스토리지 없음**
   * 상품 이미지는 파일 업로드가 아닌 **이미지 웹 주소(URL)를 입력**하여 연동합니다.

## 3. 실전 수동 테스트 시나리오 (체크리스트)

현장 운영 환경에서 아래 7가지 시나리오를 순서대로 진행하며 정상 동작 여부를 체크하십시오.

```
[테스트 진행 권장 순서]
키오스크 주문(방문/택배/맞춤) ➔ 판매장 확인 및 수납 ➔ 작업장 검수표/라벨 인쇄 ➔ 설정 변경
```

### [시나리오 1] 고객 키오스크 - 방문수령 주문 접수
- [ ] 브라우저에서 `/kiosk` 접속
- [ ] 카테고리 레일(진공세트, 프리미엄, O'meat, LA갈비 등) 클릭 시 해당 위치로 부드럽게 이동하는지 확인
- [ ] 상품 카드에서 `+`, `-` 버튼으로 수량을 변경하고 하단 장바구니 바에 수량과 금액이 정확히 합산되는지 확인
- [ ] [주문하기] 클릭 → **[방문수령]** 선택
- [ ] 주문자 이름과 연락처 입력 (전화번호 10자리 미만 시 버튼 비활성화 확인)
- [ ] **방문 날짜** 선택 후 **방문 시간(30분 단위)** 선택:
  - [ ] 오늘 날짜 선택 시, 현재 시각 이전에 이미 지난 시간대는 `[지난 시간]` 배지와 함께 선택이 차단되는지 확인
- [ ] 결제방식(카드/현금/계좌이체/나중에 결정) 선택 후 **[주문 접수]** 클릭
- [ ] 완료 화면에 **주문번호**와 수령 일시가 표시되고 장바구니가 정상 초기화되는지 확인

---

### [시나리오 2] 고객 키오스크 - 택배 주문 및 카카오 주소검색
- [ ] 상품 선택 후 [주문하기] → **[택배발송]** 선택
- [ ] 주문자 정보 입력 후, 받는 분 성함과 연락처 입력
- [ ] **[도로명주소 검색]** 버튼 클릭:
  - [ ] 카카오 우편번호 검색 팝업 창이 정상적으로 열리는지 확인
  - [ ] 도로명 주소(예: `세종대로 110`) 검색 후 선택
  - [ ] 5자리 우편번호, 도로명주소, 참고항목이 알맞게 분리되어 자동 입력되는지 확인
- [ ] 상세주소(동/호수) 입력
- [ ] *(선택 검증)* **[주소를 직접 입력할게요]** 버튼 클릭 시 수동 입력 폼으로 전환되는지 확인
- [ ] 발송 희망일 캘린더에서 발송일 선택 후 최종 주문 제출 확인

---

### [시나리오 3] 맞춤주문 (`/kiosk/custom`) 및 장바구니 결합
- [ ] 카테고리 레일의 [맞춤주문] 클릭 또는 `/kiosk/custom` 직접 접속
- [ ] 맞춤 품명 입력 (예: `한우 특수부위 모둠 1.2kg`)
- [ ] 금액 입력 (예: `180000` 입력 시 입력창에 `180,000` 쉼표 표기 및 바로 아래 `십팔만 원` 한글 금액이 뜨는지 확인)
- [ ] 요청사항 입력 (예: `살치살 위주로 포장 부탁드립니다`)
- [ ] [맞춤주문 담기] 클릭:
  - [ ] 메인 키오스크 화면으로 자동 복귀되는지 확인
  - [ ] 기존 장바구니 상품에 맞춤주문 항목이 함께 담겨 총액이 계산되는지 확인
- [ ] 주문 완료 후 판매장/작업장에 품명, 금액, 요청사항이 그대로 전달되는지 확인

---

### [시나리오 4] 판매장 (`/sales`) - 주문 모니터링 및 결제 장부 수납
- [ ] `/sales` 접속 시 **운영 암호 입력 모달**이 뜨는지 확인 (기본 암호: `0000` 또는 `.env.local` 설정값)
- [ ] 키오스크에서 접수한 주문이 2.5초 이내에 주문표에 자동 반영되는지 확인
- [ ] 상단 **결제 요약 바** 확인:
  - [ ] 총 미수금, 미결제 건수/금액, 부분결제 건수/금액, 결제완료 건수/수납액 실시간 집계 확인
  - [ ] `[총 미수금(미수 전체)]`, `[미결제만]`, `[부분결제만]`, `[결제완료만]` 칩 클릭 시 해당 주문들만 즉시 필터링되는지 확인
- [ ] 주문 행을 클릭하여 우측 상세 패널 열기:
  - [ ] **[결제/미수 장부]** 섹션에서 수납 처리 (수단: 현금/카드/계좌이체 선택, 금액 입력 후 저장)
  - [ ] 수납 후 고객 잔액이 0원으로 변경되고 주문 상태가 `결제완료`로 갱신되는지 확인
- [ ] 방문 고객 응대 시 **[고객도착]** 버튼 클릭 후 테이블에 고객 도착 표시 반영 확인
- [ ] 상단 **[CSV 다운로드]** 클릭 후 내려받은 엑셀 파일 열기 (한글 깨짐 없는지 확인)

---

### [시나리오 5] 작업장 (`/workshop`) - 타임라인 및 출고 검수표 (A4) 인쇄
- [ ] `/workshop` 접속 후 현장/택배 작업 탭 및 시간대별 타임라인 정렬 확인
- [ ] 작업 행의 상태 버튼을 눌러 `작업대기` ➔ `수락완료` ➔ `작업중` ➔ `준비완료`로 상태 전이가 원활한지 확인
- [ ] 상단 툴바의 **[출고 검수표]** 버튼 클릭:
  - [ ] 모달에 시간대별 예약 목록과 검수 체크박스(`[ ]`)가 표시되는지 확인
  - [ ] 2026 추석 정일품 작업 규격 표기 확인:
    * 봉황/팔영 구이용: `180g (162202)`
    * 봉황세트 차돌박이: `280g (162202)`
    * 오미트 시그니처 5부위: `200g (241702)` / 차돌박이 `300g (241702)`
    * 오미트 프레스티지 6부위: `230g (241702)`
    * 실속형 4부위: `V8 합포장 (600g)`
    * LA갈비 1호: `223003 용기 (900g 이상 × 2팩)`
- [ ] **[인쇄하기]** 클릭 시 브라우저 인쇄 창이 뜨며 **A4 용지 규격**으로 잘림 없이 출력되는지 실제 프린터로 시험 인쇄

---

### [시나리오 6] 작업장 - 감열 상품정보 라벨 (50×50mm) 인쇄
- [ ] 특정 주문 행의 **[라벨 인쇄]** 버튼 또는 툴바의 **[라벨 인쇄]** 클릭
- [ ] 라벨 모달에서 다음 항목이 정상 표기되는지 확인:
  - `[주문자명] – [상품명] (n/N)`
  - 예약 일자 및 시간 (또는 택배발송)
  - 결제 여부 배지 (`[결제완료]` 또는 `[미결제]`)
  - 택배 건의 경우: 보내는 분(성함/연락처), 받는 분(성함/연락처), 배송 주소 표기
- [ ] **BEEPRT BY-48 감열 프린터** 연결 상태에서 **[인쇄하기]** 클릭:
  - [ ] 인쇄 설정에서 용지 크기가 **`50mm x 50mm`**로 맞춰져 있는지 확인
  - [ ] 수량 2개 주문 시 `(1/2)`, `(2/2)` 2장이 연속 출력되는지 확인
  - [ ] 라벨 인쇄 후 불필요한 빈 라벨지가 더 배출되지 않는지 확인
- [ ] 작업 행의 상태를 `작업 중(in_progress)`으로 바꿀 때 라벨 자동 인쇄 팝업이 연동되는지 확인

- [ ] 특정 상품의 가격을 임의 변경하거나 활성/비활성(품절) 토글 후 [저장]

- [ ] 테스트 완료 후 원래 설정값으로 복구

## 4. 비상 상황 대응 가이드 (Troubleshooting)

1. **카카오 우편번호 창이 뜨지 않을 때**:
   * 고객 브라우저의 팝업 차단 설정을 해제하거나, 키오스크 주소 입력 화면의 **[주소를 직접 입력할게요]** 버튼을 클릭하여 수동으로 입력하도록 안내합니다.
2. **감열 라벨 인쇄 시 여백이 맞지 않거나 여러 장 출력될 때**:
   * 브라우저 인쇄 설정(Ctrl+P) 창에서:
     * **용지 크기**: `50mm x 50mm` (또는 감열기 설정 규격)
     * **여백**: `없음(None)`
     * **배율**: `맞춤(100%)`
     * **머리글/바닥글**: `체크 해제`
3. **운영자 화면 비밀번호가 맞지 않을 때**:
   * `.env.local` 파일의 `OPERATOR_PASSCODE` 값을 확인하십시오. (미설정 시 기본값은 `0000`입니다.)
4. **인터넷 일시 단절 시**:
   * 키오스크 화면은 입력 중인 주문 초안을 브라우저의 `sessionStorage`에 보존하므로 새로고침해도 내용이 사라지지 않습니다. 인터넷이 복구되면 주문 제출을 다시 시도합니다.
