# 페이지와 기능

## 공통 navigation과 branding

- `AppNav`는 대량주문, 메인 화면, 오늘의 장부, 판매장, 작업장, 설정으로 이동한다.
- 데이터 테이블 및 주요 조작 버튼 시야를 가리지 않도록 우측 하단 가로형 플로팅 독(바텀 시트)으로 배치하며, 원클릭 접기/펼치기 토글을 지원한다.
- 정일품 로고와 `정일품 정육식당` 표기를 공통 사용한다.
- 고정 계절 문구를 사용하지 않는다.

## 공통 금액 입력

- 금액을 직접 입력하거나 수정하는 필드는 입력 중 천 단위 쉼표를 표시한다.
- 입력 필드 바로 아래에 같은 금액을 한글 단위로 표시한다.
- 수량, 한정수량, 중량 등 금액이 아닌 숫자 필드에는 적용하지 않는다.

## `/`, `/kiosk` 고객 키오스크

### 상품

- 카테고리별 상품표시와 고정 category rail
- 상품명, 설명, 가격, 중량/구성, badge, 이미지 URL
- 사진이 없으면 placeholder
- 수량 증감, 장바구니 수량과 금액 계산
- 한정상품 잔여수량과 예약마감 표시

### 주문 초안

- 장바구니, 맞춤주문, 고객정보, 주소, 일정을 sessionStorage에 임시 저장
- hydration 이후에만 sessionStorage에 쓰기
- 뒤로가기와 맞춤주문 왕복 시 입력 유지
- 주문 성공 후 초안 제거

### 방문수령

- 텍스트형 방문수령/택배발송 선택
- 주문자 또는 회사명, 전화번호
- 캘린더 날짜선택
- 오늘과 선택 상태 구분
- 과거·마감 날짜 비활성화
- 08:00~21:00, 30분 단위 시간선택; 오늘은 Asia/Seoul 현재 시각에 이미 시작된 시간 비활성화

### 택배

- 주문자와 수령인 정보 분리
- Kakao 우편번호 검색
- 우편번호, 도로명주소, 지번주소, 참고항목 분리
- 상세주소 입력 (상세주소가 없는 단독주택·공장 등을 고려하여 선택 항목으로 지원)
- 주소 직접입력 fallback
- 발송일 캘린더
- 최종확인에서 실제 배송주소 강조

### 주문접수

- 최종 상품·수량·금액·일정 확인
- `POST /api/orders`
- 중복 제출 방지
- DB commit 성공 후에만 완료화면

## `/kiosk/custom` 맞춤주문

- 카테고리나 예산 구간 선택 없이 품명과 금액을 직접 입력
- 품명 필수, 금액은 1원 이상의 정수로 validation
- 요청사항은 구성, 부위, 포장 등 필요한 내용을 자유롭게 입력
- 완료 후 main kiosk draft의 `customItem`에 병합
- `/kiosk?resume=cart`로 복귀
- 최종 주문에서 customization row 생성

## `/sales` 판매장

- 날짜별 고밀도 주문표
- 방문수령은 pickup date, 택배는 ship date 기준
- [오늘], [전체] 빠른 날짜 프리셋 및 기간 선택(시작~종료) 지원
- 결제·미수 요약 바: 조회 기간 기준 총 미수금, 미결제 건수·금액, 부분결제 건수·잔여금액, 결제완료 건수·수납액 실시간 집계
- 원클릭 결제 필터: [총 미수금(미수 전체)], [미결제만], [부분결제만], [결제완료만] 칩 클릭으로 즉시 필터링 및 해제
- **상품별 판매 통계 모달 (`[📊 상품별 통계]`)**: 일자별(하루 기준) 및 기간별(시작일~종료일 범위) 상품 판매 수량과 합계 금액 집계. 결제 여부(결제완료/미결제)와 관계없이 접수된 모든 유효 주문을 총 수량·금액에 반영하며, 결제완료 및 미결제 건수·금액 보조 칩을 제공. 수령·발송일 기준 및 주문 접수일 기준 집계 토글 지원. 카드 뷰와 고밀도 표(테이블) 뷰 토글, 보고용 텍스트 원클릭 클립보드 복사 지원. 판매가 없는(0건) 상품은 자동 제외하고, 정일품 공식 선물세트 라인업(프리미엄 → O'meat → 진공세트 → LA갈비 → 뼈세트 → 맞춤주문) 순서대로 정렬하여 보기 쉽게 시각화. 모달 본체 단일 스크롤 및 Flexbox 축소 방지(`flex-shrink: 0`)를 적용하여 카테고리 찌그러짐 및 하단 카드 잘림 현상 방지.
- **택배 주소 카카오 도로명주소 검색 연동**: 새 주문 추가 및 작업 수정 시 수령방법이 택배(`delivery`)인 경우 키오스크와 동일하게 카카오 주소 검색 팝업을 제공하여 우편번호·도로명주소를 자동 채우고 확인 카드를 표시.
- **새 주문 추가 및 주문 수정 결제 정보·작업항목 양방향 연동**: 새 주문 추가 모달 및 주문 정보 수정 모달에서 상단 주문 결제 상태(미결제/결제완료/부분결제 드롭다운) 및 결제 금액과 하위 작업 항목의 결제 여부(미결제/결제완료)가 실시간으로 양방향 동기화되며, 결제완료 선택 시 주문 총액이 결제 금액으로 자동 반영되고 저장 시 DB에 결제 완료 상태로 안전하게 기록.
- **리스트 한눈에 보기 (인라인 노출)**: 작업 목록 및 주문 목록에서 클릭하지 않고도 상품명, 고객 요청사항(`🏷️ 요청`), 관리자 내부 메모(`📝 메모`), 맞춤주문 세부 구성(`[구성: ...]`)이 목록 행에 직접 강조 노출.
- 필터링된 미결제·부분결제 고객 명단 및 주문 목록의 즉시 확인 및 관리용 엑셀(CSV) 다운로드
  - **접수일시 및 수령일시 분리 표기/내보내기**: 주문 목록(`orderColumns`) 및 작업 목록(`columns`) 화면과 엑셀 다운로드 파일(`판매장-주문-목록`, `판매장-작업-목록`)에서 `접수일시`(주문 생성 시점)와 `수령일시`(방문수령 일시 또는 택배발송 예정일, 미등록 시 일정 미지정)를 독립된 열로 명확히 분리 제공하여 일정별 집계와 정리가 즉시 가능.
- **택배 송장 전용 엑셀 다운로드**: 택배사 송장 출력 프로그램 업로드 규격(보내는사람, 전화번호, 받는사람, 주소, 수량, 상품명, 배송메시지)에 맞춘 엑셀(CSV) 원클릭 다운로드 지원 (판매장 및 작업장 툴바 제공)
- 전체/방문/택배/상태/고객도착 필터
- 주문번호·고객명·전화번호·수령인 검색
- 날짜별 cancelled 제외, 검색에서 cancelled history와 사유 조회
- 주문 취소 사유는 `테스트`·`취소`·`직접입력` 드롭다운으로 선택하고 감사이력에 보존
- 주문 행 클릭 상세
- 메인표 인라인 수정 금지
- 맞춤주문 행은 품명과 금액을 함께 표시하고 요청사항 버튼으로 상세 박스를 연다.
- 고객도착 등록
- 작업장 상태 표시
- 동일 이름·전화번호 고객의 여러 주문을 하나의 결제·미수 장부로 집계
- **고객별 주문 묶어보기 및 미결제 총액 집계·일괄 완납 (`[👥 고객별 묶기]`)**:
  - 동일 고객 기준(공백·특수문자 제거 정규화된 동일 이름 + 동일 전화번호)으로 각 주문건을 고객 그룹 단위로 묶어서 표시.
  - 툴바의 `[👥 고객별 묶기]` 토글 버튼으로 시간순 일반 목록과 고객별 그룹 목록을 자유롭게 전환 가능.
  - 그룹 헤더 및 검색 시 상단 요약 배너에서 고객별 총 주문 금액, 기 수납 금액, **미결제 합계 금액**(미수금)을 즉시 확인.
  - 작업 목록(`tab === "work"`)에서 1개 주문에 여러 상품(작업 행)이 포함되어 있어도 주문 총액이 중복 합산되지 않도록 고유 주문(Distinct Order) 기준 정합 계산.
  - 고객 헤더의 `[💳 결제 처리]` 또는 상단 배너의 `[💳 일괄 결제 처리]`를 통해 여러 건의 미결제 주문을 한 번에 전액 결제완료(`paid`) 처리할 수 있는 `CustomerPaymentModal` 제공.
  - 목록 내 결제 배지 클릭 시 개별 주문 결제 상태/금액 변경 모달 바로 호출.
- 모든 주문이 취소되고 결제·상담 이력이 없는 고객은 장부 기본 목록에서 숨기며 구매 검색 기록은 유지
- 고객 총 주문, 순입금, 미수금, 선수금, 결제상태를 주문표와 상세에서 표시
- 결제수단(현금·카드·계좌이체), 실제 결제자 선택정보, 결제일시와 메모 기록
- 결제금액을 상품·주문에 임의 배분하지 않고 고객 총 잔액으로 계산
- 방문수령일·택배발송일 기준 예정/오늘/연체 표시
- 원본을 보존하는 결제 정정, 상담 메모 후 선택 주문 장부 분리
- 일정 미지정 legacy 주문 건수 및 검색
- legacy 주문의 fulfillment 수동 생성
- 2.5초 polling, focus/online refetch

- 전체, 작업대기, 수락완료, 작업중, 준비완료, 고객도착, 변경확인 필터
- 현장(방문수령/현장판매) 작업표: 예약 시각, 주문자(주문자명·연락처·주문번호·요청사항·수령인 구분), 상품, 수량, 작업 상태
- 택배 작업표: 주문자/수령인(수령인명·주문자명·연락처·주문번호·요청사항), 상품, 수량, 배송지 주소, 작업 상태

- 작업수락, 작업시작, 준비완료 분리

- 고객도착 주문 우선배치
- 실제 도착시각 대비 조기도착·지연 계산

  - 검수 완료 후 작업장 화면에서 즉시 '작업완료' 전환 연동
- **80*100mm 감열 상품정보 라벨 (BEEPRT BY-48 프린터)**:
  - 80mm × 100mm 감열 라벨지 최적화, 수량 N개 시 정확히 N장 출력 (`(1/N)` ~ `(N/N)`), 앞뒤 빈 용지 출력 방지 CSS
  - 표기 정보: `[상품명 (22pt)] (n/N) | [주문자명 (18pt)] [결제여부] | [날짜] [수령방식(시간/택배/배달)] | [연락처/메모/주문번호]`
  - 택배 건: `받는 분(수령인명/연락처)`, `배송주소(도로명/상세주소)`, `보내는 분(주문자명/연락처)`, `요청/메모`를 넉넉한 공간에 명확히 표기하여 송장 매칭 지원

## `/today` 오늘의 간편 장부

60대 실무자 및 프로그램 조작이 미숙한 사용자를 위한 고시인성 종이 장부 대체 전용 화면이다.

- **원터치 독립 뷰**: 일반 운영 화면의 복잡한 네비게이션바, 필터, 툴바를 배제하고 스마트폰·태블릿·PC에서 한눈에 보이는 대형 글씨(20~26px)와 고대비 카드 레이아웃 제공
- **5대 필수 항목 시인성 극대화**: `수령시간 - 주문자 - 주문상품 - 총 금액 - 결제여부`
- **주문 단위 묶음 요약**: 한 고객이 여러 상품을 주문한 경우에도 종이 장부와 동일하게 한 행에 상품 요약(`봉황 1개, 갈비 1개`)과 총 주문금액으로 집계 표기
- **방문수령 시간대별 나열**: 오늘 날짜의 매장 방문수령 주문들을 수령 시간순(`due_at` 오름차순)으로 상단 정렬
- **택배 분리 및 하단 배치**: 오늘 발송 택배 건은 목록 하단에 명확한 배너와 함께 구분 배치
- **상단 원터치 [택배만 모아보기] 탭**: 상단 대형 버튼 클릭 시 택배 주문만 배송 주소와 함께 전체 화면에 단독 집중 표기
- **대형 결제여부 배지**: `[ 결제완료 ]` (녹색/파랑) vs `[ ⚠️ 미결제 ]` (빨강 고대비 펄스)로 현장 미수금 발생 방지
- **터치 아코디언 상세**: 행 터치 시 제자리에서 고객 요청사항, 관리자 메모, 배송 주소, 세부 상품 단가 등이 부드럽게 펼쳐짐
- **현장 결제완료(수납) 원터치 변경**: 미결제 고객이 수령 현장에서 결제 시, 아코디언 상세 내 큼직한 `[ 💰 결제완료로 변경 (전액 수납 처리) ]` 버튼으로 즉시 수납 처리. 60대 실무자의 터치 실수를 방지하기 위해 큼직한 인라인 확인 다이얼로그(`[ 네, 결제완료 ]` / `[ 취소 ]`)를 제공하며, 실수 정정을 위한 `[ ↩️ 미결제로 되돌리기 ]`도 지원. 낙관적 잠금(`expectedVersion`)을 통해 타 작업자와의 동시 수정 충돌 방지
- **결제 변경 시점 자동 기록 및 표기**: 실무자가 결제완료 처리 시 변경 시점(`paid_at` 및 `work_item_events.created_at`)이 DB에 자동 기록됨. 카드 메인 배지 아래에 `🕒 오후 02:35 결제` 형태로 큰 글씨 표기되며, 아코디언 상세 영역에 `🕒 결제 완료 일시: 2026-09-16 14:35:22`가 명확히 표시되어 수납 시각에 대한 분쟁이나 착오를 원천 방지
- **실시간 자동 동기화**: `useResource`를 활용하여 5초 주기로 최신 주문을 자동 반영하며 상단 수동 `[ 🔄 새로고침 ]` 버튼 제공
